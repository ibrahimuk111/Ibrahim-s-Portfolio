# Facial Emotion Recognition

A deep learning system that classifies facial expressions (happy, sad, angry, surprised, neutral, fear, disgust) from images and live webcam feed, trained on the FER2013 dataset.

## Features

- CNN model trained on FER2013 (dataset included in `Dataset/`)
- Real time emotion detection from webcam using OpenCV
- Sample outputs available in `Output/`

## Files

- `main.py` — real time webcam emotion detection
- `implementation.py` — model implementation and training code
- `Dataset/` — FER2013 dataset archive
- `Output/` — sample results

## How To Run

1. Install dependencies: `pip install tensorflow opencv-python numpy pandas`
2. Extract the dataset zip inside `Dataset/`
3. Train with `python implementation.py`, then run `python main.py` for live detection
