# Computer Vision Projects

A curated collection of applied computer vision projects by **Muhammad Ibrahim**, spanning medical imaging, security, industrial inspection, safety systems, and generative image enhancement. Each project is self contained with its own `README.md`, code, and where practical, datasets or sample media.

## Project Index

- `AI Super-Resolution and Image Restoration/` — Image denoising, restoration, and super resolution
- `Anomaly Detection in Industrial Inspection/` — Detect manufacturing defects for quality control
- `Automatic Number Plate Recognition/` — YOLOv9 plate detection + OCR on vehicle video
- `Blinking and Drowsiness Detection/` — Driver safety monitoring via eye state analysis
- `Blood Cell Cancer Detection/` — Leukemia classification with CNN and EfficientNetB3
- `Brain Tumor Detection/` — MRI tumor classification using CNN, MLP, and VGG16
- `Car Detection using Drone/` — Vehicle detection from aerial drone footage
- `Deep Fake Video Detection/` — Detect AI manipulated videos
- `Digital Image Tampering Detection/` — Image forensics for detecting edited images
- `Eye Diseases Detection/` — Classification of eye diseases from retinal images
- `Face Liveness Detection System/` — Anti spoofing for face authentication systems
- `Facial Emotion Recognition/` — Real time emotion classification on FER2013
- `Fire Detection YOLOv8/` — Real time fire detection for safety monitoring
- `Image Captioning/` — Generate natural language descriptions of images (CV + NLP)
- `Lung Cancer Detection/` — Lung cancer classification from medical scans
- `Self Driving Car/` — Lane detection pipeline for autonomous driving

## Tech Stack

Python, OpenCV, TensorFlow/Keras, PyTorch, YOLOv8/YOLOv9, EfficientNet, VGG16, dlib, scikit-learn
