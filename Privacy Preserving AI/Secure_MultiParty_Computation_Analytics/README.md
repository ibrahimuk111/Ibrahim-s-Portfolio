# Secure_MultiParty_Computation_Analytics

Secure Multi-Party Computation framework for privacy-preserving analytics across joint data silos.

## Architecture

```
Secure_MultiParty_Computation_Analytics/
├── src/           # Core modules
├── tests/         # Unit tests (pytest)
├── app.py         # Application entry point
├── Dockerfile     # Container configuration
├── requirements.txt
└── LICENSE
```

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run application
python app.py

# Run tests
pytest tests/ -v

# Docker
docker build -t secure_multiparty_computation_analytics .
docker run -p 8000:8000 secure_multiparty_computation_analytics
```

## Features
- Shamir Secret Sharing simulation
- Joint cross-party statistical analytics
- Zero raw data disclosure guarantees
